# 🍕 Pizza Sales Performance Analysis (SQL & Tableau)

### 📊 Project Overview
Bu proje, bir pizza restoranının satış verilerini kullanarak iş performansını optimize etmeyi amaçlar. Ham veriler SQL ile işlenmiş ve Tableau üzerinde interaktif bir dashboard'a dönüştürülmüştür.
![Pizza Sales Dashboard](Screenshots/pizza_dashboard.PNG)

### 🛠️ Tech Stack
- **Database:** SQL (PostgreSQL/MySQL)
- **Visualization:** Tableau
- **Analysis:** Excel

### 🚀 Key Technical Features
- **SQL Analytics:** `JOIN`, `CTE`, ve `Window Functions (RANK, PARTITION BY)` kullanılarak gelişmiş veri manipülasyonu yapıldı.
- **Data Modeling:** Ham veriler analize uygun "Master Table" yapısına getirildi.
- **Interactive Dashboard:** Tableau üzerinde `Dual Axis`, `Action Filters` ve `Time Series` analizleri uygulandı.

### 💡 Business Insights
- **Rush Hours:** Öğle (12:00-13:00) ve akşam (17:00-19:00) saatlerindeki yoğunluk tespit edildi.
- **Product Mix:** "The Thai Chicken Pizza" ciro lideri olarak belirlendi.
- **Size Trends:** "Large" boy pizzaların toplam gelirin en büyük payını oluşturduğu kanıtlandı.
